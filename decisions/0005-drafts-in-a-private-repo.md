# 0005 Drafts live in a separate, private repository

- Question: where do the editions themselves live, from first draft to published edition?
- Options: in this repository under `editions/`; in a new public repository; in a new private repository.
- Choice: a new private repository under bitz GmbH, one folder per edition, one issue per edition. Agents work on `dev`, and my final yes (stage 9) is the merge into `main`. This repository keeps the build story: log, decisions, map and skills. The empty `editions/` folder is removed from here.
- Why: drafts stay unseen until I approve them. This repository stays public, because how the system is built is meant to be followed while it is built. Published editions still appear in public, on the website and by email.
