# 0004 Editions are Quarto documents

- Question: in which format is an edition written?
- Options: a Quarto document (`.qmd`); plain Markdown (`.md`).
- Choice: a Quarto document. Each edition is an `index.qmd` with its data and code next to it.
- Why: editions carry charts and numbers. By principles 1, 2 and 6 in [reproducibility.md](../reproducibility.md), charts come from code, numbers come from inline code, and a file with code to render is a Quarto document. The same source can render the web page and the text for the email.
