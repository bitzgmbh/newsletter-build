# 0030 Englisch als eigene Mail

- Frage: Was bekommen englischsprachige Leser:innen von jeder Ausgabe? (offene Frage 1)
- Optionen: eine kurze Zusammenfassung am Ende; eine volle Übersetzung; Englisch nur auf LinkedIn; eine englische Fassung für einzelne Ausgaben.
- Wahl: Eine volle Übersetzung als eigene Mail. Stufe 8 bleibt auf der Karte, der Skill `uebersetzung` schreibt `index-en.qmd`, und die App legt dafür einen zweiten Entwurf in Buttondown an.
- Warum: Mein Netzwerk ausserhalb des deutschen Sprachraums soll die Ausgaben lesen können, ohne dass die deutsche Mail länger wird.
- Offen: Wer die englische Mail bekommt. Dafür braucht Buttondown einen Filter (Tag oder Feld), und 0026 erlaubt im Formular nur eine Frage. Das hängt an der offenen Frage 2. Bis dahin bleibt der englische Entwurf ein Entwurf ohne Filter.
- Datum: 2026-11-03
