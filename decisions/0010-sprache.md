# 0010 Das Repository läuft auf Deutsch

- Frage: In welcher Sprache wird dieses Repository geschrieben?
- Optionen: alles auf Englisch wie bisher; alles auf Deutsch, mit einer kompletten Übersetzung; Deutsch für neue und grösser geänderte Texte, Englisch für Commits, Code und Skills.
- Wahl: Deutsch für alles, was ich schreibe und lese: Konzept, Entscheidungen, Logeinträge, Pipeline Dateien und README. Bestehende Dateien werden übersetzt, sobald sie das nächste Mal grösser geändert werden. Commit Messages, Code mit seinen Kommentaren und die Skill Dateien bleiben auf Englisch. Ein englischer Absatz oben im README hält das Repository für mein internationales Netzwerk auffindbar.
- Warum: In meiner Muttersprache schreibe ich klarer und genauer, und der Newsletter erscheint zuerst auf Deutsch (Entscheidung 0009). Eine komplette Übersetzung kostet Zeit an Dateien, die sich am Retreat ohnehin ändern. Commit Messages folgen Conventional Commits, und `disclosure-summary.R` liest ihre Trailer. Skill Dateien lesen Agenten, und ich teile sie.
- Datum: 2026-10-17
