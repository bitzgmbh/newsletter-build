# 0040 Offengelegt in Sätzen, mit bestätigten Sätzen und einem Link

- Frage: Wie liest sich der Block "Offengelegt" einer Ausgabe (0017, 0020), damit er Leser:innen etwas erzählt und als Erklärung zum Einsatz von KI taugt?
- Optionen: die Stichworte pro Stufe behalten (0017); den Block von Hand schreiben; den Block in Sätzen aus den Spuren erzeugen und um Sätze ergänzen, die ich bestätige.
- Wahl: Sätze aus den Spuren, ergänzt um bestätigte Sätze. `skills/offenlegung/offenlegung.R` schreibt einen Satz dazu, wer den Text geschrieben hat, dann eine Zeile pro Verb für das, was Claude Code getan hat (Recherchiert, Gegliedert, Geprüft, Vorgeschlagen, Gebaut, Übersetzt, Verbreitet), das Modell mit seinem Produktnamen, den Satz "Die Ideen, die Entscheidungen und das letzte Ja sind von mir." und einen Link auf `disclosure.md` in diesem Repository. Was keine Spur allein hergibt, steht als Satz in `offenlegung.md` neben der Ausgabe, eine Zeile pro Schlüssel, auch `Text` und `Rückmeldung` (Menschen, die den Entwurf vor dem Versand gelesen haben). Claude Code entwirft diese Sätze aus `pruefpunkte.md` und den Commit Nachrichten der Ausgabe, ich bestätige sie, und das Skript setzt sie ein. Ein Satz ersetzt die Vorgabe seines Schlüssels oder ergänzt eine Zeile. Die englische Fassung (0030) entsteht mit `--en` aus denselben Spuren und `offenlegung-en.md`. Die Zeilen "Sitzungen" und "Prompts" stehen nicht mehr im Block; das Skript nennt sie mir beim Lauf. Eine Stufendatei, die nur "Entfällt" sagt (0037), gilt nicht als Lauf.
- Warum: Die Stichworte nannten die Stufen der Pipeline in den Worten des Build Systems. Niemand ausser mir weiss, was eine Sitzung ist, das Modell stand als interne Kennung da, und nichts liess sich nachprüfen, weil das Repository der Ausgaben privat ist. Ein Block ganz von Hand käme aus der Erinnerung (Prinzip 7). Die bestätigten Sätze liegen als Datei neben der Ausgabe und sind damit selbst eine Spur: Wer sie geschrieben hat, steht im Commit.
- Anlass: Durchsicht der Ausgabe 2026-11-12-wie-lernt-man-r-am-besten, Issue 6. Der Block dieser Ausgabe entstand am 12. November zuerst als Ausnahme von 0017 von Hand und kommt jetzt wortgleich aus dem Skript.
- Offen: ob die Namen der Personen, die Rückmeldung geben, im Block stehen (nur mit ihrem Ja); eine deutsche Seite zur Offenlegung, sobald der Newsletter eine eigene Website hat (0022, 0023).
- Ändert: 0017 (Stichworte pro Stufe), 0031 (Länge des Blocks: etwa 80 bis 100 Wörter statt 50).
